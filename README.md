# Al-Qaddaary Telegram Archive v9

Preview-theme fixes.

## v9 changes

- The whole controls/search/filter container now has padding and rounded borders.
- Timeline nodes are vertically centered in each post instead of overlapping the time text.
- Time column widened and padded away from the spine.
- Gold hover highlight on posts removed.
- Metadata popover now includes "Copy post text".
- Custom audio progress supports click and pointer dragging, including touch/Android.
- Audio preload changed to metadata for better seeking readiness.
- v8 preview-inspired theme retained.

## Run locally

```bash
python3 -m http.server 8080
```

Open:

```txt
http://localhost:8080
```
